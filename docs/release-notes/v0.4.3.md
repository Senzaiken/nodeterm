**If you use hold-to-talk dictation, take this release.** A support report traced a bug that had
been there for many versions: after a short Cmd+Alt tap — or any Cmd+Opt shortcut, or the window
simply losing focus — the microphone could stay open and keep typing into your selected terminal,
one line every couple of minutes for about ten minutes. Sometimes what it typed was speech from the
user's meetings. Opening a microphone is asynchronous, and the overlay could close before the
capture handle existed, so the cleanup found nothing to cancel and the capture lived on alone.

**A run node.** VS Code's "Run Without Debugging" for any `.vscode/launch.json` configuration, as a
node on the canvas: pick a folder, a configuration or compound, and for Flutter a device, then
Run / Stop / Restart — with hot reload, hot restart and reload-on-save. It is under **New view ▸ New
run configuration** (⌘K: "New run configuration"). Several run nodes can live in one project, each
pointed at a different checkout and simulator, which is the case it was built for.

**Canvas and window handling.** Terminals resize from every edge with Liquid Glass on, the grab zone
is wider, and a hovered terminal now keeps the keyboard after the pointer leaves — sloppy focus, the
way a tiling window manager does it.

**Live links get a Figma-style create dialog**, and **Billing & invoices** opens the Stripe customer
portal, so a desktop buyer can fetch their own invoice.

Smaller, but you will meet them: every agent confirmation now offers "don't ask again for agents in
this project"; writing agent config asks first, and skills replace the old `AGENTS.md` marker
blocks; chat-view prompts arrive as typed text instead of a paste; bulk agent restarts stream their
progress with bounded concurrency; arrange can work by lineage and inside a group; and the shared
GPU renderer draws strikethrough.
